# DevPulse 🚀

> A full-stack developer analytics platform that transforms GitHub activity into meaningful insights through data visualization, API integration, and intelligent analysis.

## 📌 Overview

DevPulse helps developers understand their coding journey by analyzing GitHub data and presenting it in an interactive dashboard.

Users can search for a GitHub username and explore:

- Developer profile information
- Repository statistics
- Most used programming languages
- Contribution activity
- Coding consistency
- Developer growth insights

The goal of DevPulse is to turn raw GitHub activity into a clear picture of a developer's progress and skills.

---

## ✨ Features

### 👤 Developer Profile Analysis

- Fetch GitHub user information
- Display profile details, followers, repositories, and bio

### 📊 GitHub Statistics Dashboard

- Total repositories
- Contribution activity
- Coding activity trends
- Popular programming languages

### 📚 Repository Insights

- View top repositories
- Repository descriptions
- Stars and forks
- Language usage

### 🔥 Contribution Heatmap

- Visualize coding activity over time
- Track contribution patterns

### ⚡ Smart Caching System

- Reduces unnecessary GitHub API requests
- Stores frequently accessed data
- Improves performance

### 🚨 Error Handling

Handles:

- Invalid usernames
- GitHub API failures
- Rate limit issues
